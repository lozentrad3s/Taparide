# Taparide

Taparide (**Tap A Ride**) is a multi-tenancy transport app: the Abuja Smart Mobility Platform for riders, transport operators, fleet owners and the FCTA, built for ATDEW 2026.

**The app lives in [`taparide_flutter/`](taparide_flutter/).** See its [README](taparide_flutter/README.md) for features, demo accounts, Supabase setup and how to run it.
